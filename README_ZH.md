# SPIN//BREAK ARENA V10 · IMPACT & CHAOS ARENA

V10 建立於 V9.3 的 Rapier 3D 物理、576 種改造與 3D 陀螺造型之上。V9.2 的護欄及「強力對手撞擊才可在南北缺口出界」規則保留。

## 主要玩法

- **衝鋒 CHARGE**：點選對手後施放，利用高速碰撞角度爭取精準重擊。
- **反擊 PARRY**：0.55 秒反擊窗口、6.8 秒冷卻，判斷對手衝鋒時機可反彈敵人；按錯會浪費轉速及冷卻。手機按「反擊」，鍵盤 K。
- **隨機場地異變（預設啟用）**：第一個事件約在第 7–10 秒預警，預警 2.2 秒後生效，後續事件間隔約 9–13 秒，不連續轟炸。
- 五種異變：**深淵黑洞**（中心牽引）、**隕石碎片雨**（五顆真正的 Rapier 3D 墜落剛體、有落點預告）、**極速風暴**（左右擾動）、**雙極磁場**（中央斥力）、**重力震盪**（擴散波）。同局不連續重複同一種。
- 事件有標示預警、剩餘時間、場上的 3D 視覺模型；所有碰撞及外力均以伺服器為準。
- 房主可在大廳切換「開啟隨機異變／關閉純競技」，所有玩家同步。
- 建議單人加 1 AI 練習 1v1；最多 4 人同房競技。

## 驗證

`npm install` 在 Render 觸發 `postinstall`：3D 物理、V9 改造、護欄、出界、V10 隨機異變及 4 人 WebSocket 測試。
`npm run test:chaos` 額外檢查預警、五種事件、真 3D 碎片碰撞器、反擊冷卻、純競技關閉事件。

## 限制

- 特效與 3D 物理仍是遊戲化表現；不是完整的實體陀螺動力學。
- Render 免費層可能閒置休眠；Safari WebGL 的真機畫面與實際手感需要真人驗收。
- 隕石碎片使用簡化剛體形狀與有限生成數量，避免四人手機對戰負載過高。
- 隨機事件不設直接傷害或瞬間判負，仍需透過一般旋轉停止或合法出界判定淘汰。

參考：Rapier 3D 受力與衝量 https://rapier.rs/docs/user_guides/javascript/rigid_body_forces_and_impulses/


## V10.1 多人同步修正

- 物理步進與 3D 狀態廣播合併在同一個 30Hz 伺服器影格，不再由獨立的 20Hz 計時器取樣；每次更新有 `round`、`seq` 與 `serverNow`。
- 伺服器對同一房間所有玩家廣播**完全相同**的權威 3D 快照。
- 用往返 ping 校準時間與 160ms 同步播放緩衝，各台電腦使用同一條服務端時間軸插值位置，而非各自追趕最新快照。
- 以不斷累積的旋轉角度顯示高速陀螺，避免旋轉超過單幀 180° 時 quaternion 插值顯示反向或跳動。
- 所有碰撞事件依物理時刻與畫面同步；結束前會送出最後的完整狀態。
- 保留 V9.2 護欄、出界保護及 V10 隨機競技場效果與反擊能力。
- 驗證：`npm run test:sync`、`npm test`（四客戶端同影格逐欄相同的快照），以及既有 Rapier 與競技場回歸測試。

注意：這是同步機制的工程修復；仍需真實的四台電腦在不同延遲環境中驗收感受。
