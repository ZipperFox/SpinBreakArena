# SPIN//BREAK ARENA V5.0 — 自走陀螺／衝鋒物理對戰

正式網站：https://spin-break-arena.onrender.com
原始碼：https://github.com/ZipperFox/SpinBreakArena

## 本版玩法：不用搖桿推陀螺

陀螺會依刀刃、重量、軸心、場地和物理動量自主繞場運動。玩家不再能直接移動陀螺，而是**選定目標並在合適時機衝鋒**，或啟動每款陀螺的專屬必殺技。碰撞本身會讓陀螺彈開、失穩、失去轉速，最後以**擊出場外／停轉**分出勝負。沒有 HP 血量。

- 手機：點對手或按「切換鎖定目標」選擇鎖定對象；右下「衝鋒」為一次性加速撞擊；「必殺」啟動角色特色技能。
- 鍵盤：`Tab` 切換鎖定、`Space` 衝鋒、`J/K` 必殺。WASD／方向鍵不會控制陀螺移動。
- 衝鋒：短時間強力動量推進，約 4.3–4.7 秒冷卻，每次耗費約 3.6 點轉速，衝鋒中接觸可強化撞擊。衝鋒時不可任意轉向，時機與站位很重要。
- 必殺：每款陀螺有不同效果，冷卻依角色而異；也會耗費轉速。
- 反彈：加大碰撞衝量，降低自走導向力對撞擊的干擾；雙方完全分離並在短暫接觸期避免重複結算衝量。不代表完整 3D 剛體／接觸摩擦模擬。

## 場地與改造

- 5 座競技場：王者競技場、深淵漩渦、雷暴聖域、熔岩裂谷、終焉日蝕。
- 場地含物理護欄／防撞墩／左右回場通道；南北出界口仍可能直接造成出界淘汰。
- 12 款刀刃 × 6 種棘輪 × 8 種軸心 = **576 種配置**。所有零件開放免費選擇，決定速度、慣性、穩定、摩擦與加速軌道效率，但尚未全面測試 576 種組合的對戰平衡。
- 支援 2–4 人即時 WebSocket 房間，可與 AI 對戰，分享房間邀請碼、斷線 90 秒內恢復。

## 啟動與測試

使用 Node.js 22 以上版本，在程式根目錄執行：

```bash
node server.js
```

可透過 `http://localhost:3000` 進入。公開伺服器可用 Render Node Web Service 自動部署，啟動命令 `node server.js`。

```bash
node test_physics.js    # V4 舊有物理回歸測試
node test_v5.js         # V5 自走／衝鋒／反彈／防黏連測試
node test_multiplayer.js  # 需先啟動本機伺服器
node test_remote_v2.js    # 需先啟動本機伺服器
node balance_check.js 200
node verify_live.js https://spin-break-arena.onrender.com
```

已確認本機伺服器 4 人房間與重連流程、HTTP/WebSocket 及 2D 物理測試。AI 模擬只能代表特定控制策略，**不等同真人手感或配裝平衡驗收**。公開伺服器及手機 Safari 的使用狀況，應以實際上線後測試結果為準。

## 安全與成本

本作為小型多人原型，房間資料存在單一進程記憶體，服務休眠、重新部署或重啟時房間會消失；沒有持久資料庫、登入、防 DDoS 或大型配對系統。Render 免費方案可能休眠與限制資源，部署和額度應以 Render 官方頁面為準。

參考設計原理：TAKARA TOMY／Hasbro 的戰鬥陀螺產品介紹說明，陀螺的刀刃、棘輪、軸心和場地加速軌道會影響碰撞表現。本遊戲為原創設計，不使用品牌商標或授權模型，亦不聲稱是具備完整真實物理精度的模擬器。
